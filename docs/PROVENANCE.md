# Provenance and learning scope

The original Java product catalog is from rgabhi/productservice at ae93c98be9874faf1a9283aa761058c945afcd87 and remains in legacy/java-productservice/. Its history is preserved on this rebuild branch.

The Python student checkout was implemented with assistant help in November 2026, after the user requested a concept-focused learning application. It is not backdated to the original Scaler work and does not claim that the user personally authored or has already learned every new line.

The larger system-design plan was deliberately reduced: one product per order, simulated approve/decline payment, simple compensation, durable outbox/inbox, stock correctness and a catalog cache. Advanced production recovery, real payments and performance claims are excluded. Implementation checks and user study completion are recorded separately.
